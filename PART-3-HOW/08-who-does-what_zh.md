# 第八章：谁做什么

> "最好的领导者，是那些有智慧去挑选合适的人来完成工作，并有自制力在他们工作时不去干涉。"
> — 西奥多·罗斯福 (Theodore Roosevelt)

**每个公司都始于同一个问题：谁做什么？**

AI Agent 不会改变这个问题，而是让它**更加尖锐**。
- **人类员工**：会即兴发挥、提问、在走廊里捕捉线索。
- **Agent**：**不能**。它们需要明确的角色、硬性边界和清晰的汇报关系。

没有这种结构，你得到的是**昂贵的混乱**，而非一家公司。
如果你想拥有一家在你睡觉时也能运行的企业，就要像 CEO 一样思考。**CEO 的首要工作就是决定谁做什么**。

---

## 🎯 角色，而非工具
大多数人购买 AI 的方式像买家电：
- "我需要一个写博客的工具。"
- "我需要一个分析数据的工具。"
- "我需要一个回复客户邮件的工具。"

**他们在购买功能**。

而 CEO 雇佣的是**角色**：
- "我需要一个内容写手。"
- "我需要一个数据分析师。"
- "我需要一个客服代表。"

**区别不是语义上的**。工具被放在抽屉里；角色则坐在组织中，拥有职责、权限和汇报对象。

在 Paperclip 中，**每个 Agent 都填充一个角色**：头衔、职责、层级位置、与其他 Agent 的关系。
你不是在安装软件，而是在**为某个职位招聘**。

### ✅ 测试方法：
> **如果这个岗位要雇佣一个人类，职位描述会怎么写？**
> 写下那个描述 → 你就得到了角色定义。

## 🏢 四种组织架构图（示例）
以下是零员工公司的四种结构。它们是假设性的，请根据实际情况调整。

### 1️⃣ 内容发布公司 (Content Publisher)
最常见的起点，因为内容是当前 AI Agent 表现最好的领域。

```text
你 (创始人/CEO)
├── 编辑总监 Agent
│   ├── 写手 #1 (长篇文章)
│   ├── 写手 #2 (短文/社交媒体)
│   └── SEO Agent
├── 发布 Agent (排期、发布)
└── 分析 Agent (流量、互动追踪)
```

**如何运作**:
- **你设定编辑策略**：主题、语调、受众、目标。
- 编辑总监将其转化为任务分配。
- 写手起草 → SEO Agent 优化 → 发布 Agent 排期分发 → 分析 Agent 报告表现。

**你负责**: 策略、语调、标记内容（需人工审查）、客户关系。

---

### 2️⃣ 电商公司 (E-Commerce)
```text
你 (创始人/CEO)
├── 产品研究 Agent
├── 文案撰写 Agent (商品列表、描述)
├── 客服 Agent
├── 库存/定价 Agent
└── 营销 Agent (邮件、社交媒体)
```

**如何运作**:
- **产品研究**：追踪趋势和竞品。
- **文案撰写**：生成并更新商品列表。
- **客服**：处理咨询，将异常情况升级给你。
- **库存/定价**：监控库存并建议价格调整。
- **营销**：运行邮件和社交媒体活动。

**你负责**: 产品选择、供应商谈判、品牌管理、升级投诉处理。

---

### 3️⃣ SaaS 支持公司 (SaaS Support)
```text
你 (创始人/开发者)
├── QA Agent (测试、Bug 检测)
├── 文档 Agent
├── 客服 Agent (工单处理)
├── 营销 Agent (博客、社交媒体、邮件)
└── 分析 Agent (使用数据、流失信号)
```

**如何运作**:
- **你构建产品**。
- QA 测试 → 文档更新帮助页面 → 客服回答工单和常见问题。
- 营销撰写并推广内容 → 分析监控用户行为并标记流失风险。

**你负责**: 代码、架构、关键客户、战略方向。

---

### 4️⃣ 代理公司 (Agency)
```text
你 (创始人/客户总监)
├── 项目经理 Agent
│   ├── 专家 #1 (根据服务变化)
│   ├── 专家 #2
│   └── 专家 #3
├── 客户沟通 Agent (状态更新、报告)
└── 商务拓展 Agent ( outreach、提案)
```

**如何运作**:
- **你获取客户并界定工作范围**。
- 项目经理拆解任务并分配给专家。
- 专家执行 → 客户沟通发送更新和报告 → 商务拓展寻找新客户。

**你负责**: 客户关系、范围界定、质量审查、方向把控。

> **这些是模式，而非处方**。你的公司会有自己的形态。**原则不变**：命名角色、分配职责、绘制边界。

## 📝 角色定义包含什么？
Agent 的输出取决于其角色定义。**这里偷懒，后期必买单**。

| 要素 | 说明与示例 |
|------|-----------|
| **Title (头衔)** | 这个角色的名称是什么？（如 "Content Writer"） |
| **Duties (职责)** | Agent 具体做什么？**越具体越好**。<br>❌ "处理内容"（模糊）<br>✅ "撰写 1000-1500 字的博客文章，遵循公司风格指南，针对目标关键词优化，以 Markdown 交付"。 |
| **Authority (权限)** | Agent 能独立决定什么？什么需要审批？<br>• 写手：可自由选择小标题，但主题需批准。<br>• 客服：可处理 $50 以下退款，超过则升级。 |
| **Boundaries (边界)** | Agent **绝不能**做什么？<br>• "不直接联系客户"<br>• "不进行采购" |
| **Standards (标准)** | 什么是好工作？**给出示例**。<br>• "文章必须准确、使用主动语态、包含至少三个小标题，并以行动号召结尾。" |
| **Reporting (汇报关系)** | 谁向这个 Agent 汇报？它向谁汇报？它与谁协作？ |

**你在这一部分消除的每个模糊点，都是你未来永远不会遇到的管理问题**。

## 🔄 工作流如何流动？
在 Paperclip 组织图中，**层级决定工作的流向**。

| 方向 | 说明 |
|------|------|
| **向下 (Down)** | 公司目标从顶层进入 → 高级 Agent 拆解为小任务并分配 → 直到每个任务具体到可由单个 Agent 完成。 |
| **向上 (Up)** | 结果向上传递 → 每一级审查、汇总或处理从下层上来的内容。 |
| **横向 (Sideways)** | 同级 Agent 之间传递工作。<br>• 写手 → SEO Agent（草稿）<br>• SEO Agent → 发布 Agent（优化后文案）<br>**你在组织结构中定义这些交接点**。 |

### 🏗️ 扁平 vs. 分层？
- **扁平 (Flat)**：你直接指挥 Agent，无中间层。<br>适合 3-5 个执行独立任务的 Agent。简单，你直接看到一切。
- **分层 (Layered)**：你指挥经理，经理指挥员工。<br>适合 6+ 个 Agent、重叠任务或你无法独自审查的工作量。经理过滤：他们检查工作，**你只看成品或标记的问题**。

> **策略**: 从扁平开始。当你花在审查输出上的时间多于思考方向时，添加层级。

## 🧠 运行时注入新技能
Paperclip 允许你**在不重建 Agent 的情况下注入新技能**：
- 给写手新的风格指南。
- 给 SEO Agent 最新的关键词方法。
- 给客服 Agent 产品发布简报。

Agent 吸收新材料并保留旧知识。
**两个后果**:
1. **持续改进**：随着你了解什么有效，不断注入更精准的指令。
2. **快速转型**：新竞品？加载竞争分析给分析师。新内容方向？更新编辑总监。季节性变化？重新调整 Agent 而无需重画整个图表。

## 👤 一位创始人，十个角色
在零员工公司中，你的工作性质发生了变化。你不再"做工作"，也不再以旧方式"监督"。**你设计组织并做出 Agent 无法做出的决策**。

### ✅ **你做**:
- 设定战略和目标。
- 设计并调整组织架构图。
- **审查标记的输出**（而非所有输出，只需你判断的部分）。
- 在资金、关系和道德方面做出高风险决策。
- 注入技能并调整角色。
- 监控预算和公司级数据。

### ❌ **你不做**:
- 撰写初稿。
- 处理常规任务。
- 日常协调 Agent（层级结构负责）。
- 检查每个交付物（审计日志负责；你按自己的节奏审查）。

这是"一位创始人，十人团队"方程的实际应用：**你在 CEO 层面工作，而 Agent 负责执行**。你花在战略和结构上的每一小时，都会通过下方的每个 Agent 放大。

---

## 🚀 从三个 Agent 开始
**先从三个 Agent 起步，不要更多**。

选择当下能产生最大影响的三项工作。仔细定义它们的角色、分配任务、观察它们的行为。**运行一到两周后，再添加第四个**。

诱惑是第一天就设计一个 15 Agent 的公司。**抵抗它**。
每个 Agent 都是：
- 需要定义的角色。
- 需要管理的汇报关系。
- 需要设置的预算。

**从你已知的开始，而非猜测**。
