# 第十一章：你不是可选项

> "计算机 incredibly fast, accurate, and stupid（快、准但傻）。人类 incredibly slow, inaccurate, and brilliant（慢、不准但卓越）。两者的结合是超越计算的力量。"
> — 里奥·谢尔纳 (Leo Cherne)

AI Agent **会幻觉**、**做出错误判断**、**产出让你尴尬的内容**，并**以十足自信做错事**。

任何告诉你"AI 能在无人监督下运营公司"的人，要么在推销什么，要么还没真正尝试过。
**零员工 ≠ 零人类**。它意味着：**一个具备良好判断力的人类，运营一家 AI 负责劳动、你负责决策的公司**。

本章至关重要：**知道 AI 不能做什么，与知道它能做什么同样重要**。
成功于此的创始人不会是"对 AI 最乐观的人"，而是"**最清醒的人**"。

## ⚠️ 四种失败模式
AI Agent 以特定且可预测的方式失败。**提前了解，你就能治理规避，而非被 surprise**。

| 模式 | 说明与应对策略 |
|------|--------------|
| **1. 幻觉 (Hallucination)** | 语言模型通过预测训练数据中最可能的下一个词生成文本。有时这个"最可能"的词是错的。<br>模型会**产生自信且看似合理但虚假的陈述**。<br><br>**这不是下个季度能修复的 bug**。它内置于模型工作原理中，将持续存在。<br><br>**公司规则**：<br>• 对事实性陈述的 Agent 输出，**必须验证**。尤其是客户内容、财务数据或出错有后果的场景。<br>• 编辑 Agent 应审查写作 Agent。<br>• **治理闸门**拦截准确性不可妥协的内容。<br>• 即使对未设闸门的输出，也要定期抽查。 |
| **2. 歧义 (Ambiguity)** | Agent 在任务清晰、成功标准明确时表现最佳。<br>当情况模糊、正确答案依赖数据之外的上下文、存在多种有效方案、或决策需要在不同价值尺度间权衡时，Agent 会动摇。<br><br>**示例**：<br>• 愤怒邮件（表面是退款请求，实则是渴望被倾听）。<br>• 内容简报有三种解读方式（正确选择取决于 Agent 缺乏的受众细微差别）。<br>• 定价决策需平衡短期收入与长期品牌定位。<br><br>**这些是判断力决策**，需要多年生活经验积累的模式识别（训练集无法完全捕捉）。Agent 会做选择，但可能不像你。 |
| **3. 语气 (Tone)** | AI 可产出技术上正确但**语调错误**的内容：<br>• 该随意时太正式。<br>• 该冷静时太热情。<br>• 该体现品牌独特性时太通用。<br><br>**这在快速改进**。但对于"语气即品牌"的业务（*如何说*与*说什么*同样重要），你需要**对敏感语气的内容进行人工审查**。至少设置详细的语调指南，并闸门任何语气失误可能损害品牌的内容。 |
| **4. 原创性 (Originality)** | AI 在既定模式中产出好作品：<br>• 能写符合现有风格的博客。<br>• 生成遵循最佳实践的产品描述。<br>• 产出覆盖预期领域的分析。<br><br>**但它不擅长创造新事物**：<br>• 打破惯例的活动方案。<br>• 前所未有的声音/风格。<br>• 训练数据中不存在的概念。<br>• 让人在滚动时停下的独特文字。<br><br>**品味与原创性仍是人类优势**。如果你的业务依赖非凡创造力，**愿景来自你**。 |

## 🎯 CEO，而非乘客
你不做具体工作，但也不忽视它。你**审查、指导、决策并在需要时干预**。
- **信任团队但核实**（Trust but verify）。
- **授权但不弃权**（Delegate but do not abdicate）。

### 实践指南：
| 行动 | 说明 |
|------|------|
| **设定明确标准** | Agent 必须确切知道"好工作"的样子。角色定义、风格指南和质量准则越具体，你干预越少。 |
| **审查重要内容而非全部** | 无需阅读每个输出。利用审计日志和审批闸门聚焦异常、标记项和高价值交付物。 |
| **修复系统而非症状** | Agent 产出差工作时，答案很少是"手动重写输出"。<br>**优化角色定义、任务简报或质量标准**。改进机器本身。 |
| **毫不犹豫覆盖** | 某些情况需要你的直接判断。**Agent 为你工作，你的决定是最终的**。 |
| **接受不完美** | Agent 不会每次都产出完美工作（人类员工也不会）。问题不是"这完美吗？"而是"**这足够好吗？系统是否在改进？**" |

## 👑 只有你能做的五件事
| 职责 | 说明 |
|------|------|
| **1. 战略 (Strategy)** | 进入哪些市场？构建什么产品？在哪里竞争、哪里差异化？**需要解读趋势、看清数据未言明之处，并在信息不全时下注**。 |
| **2. 关系 (Relationships)** | 关键客户、合作伙伴、投资者、社区。<br>AI 可支持关系管理（提醒、研究、起草消息），但**关系本身存在于人与人之间**。 |
| **3. 品牌 (Brand)** | 公司代表什么？如何发声？**拒绝做什么**。<br>品牌反映人类价值观。AI 可执行你的品牌，但**由你定义**。 |
| **4. 伦理 (Ethics)** | 当正确决策不清晰时。<br>客户信任受威胁时。盈利选择与责任冲突时。**这些决策必须由承担后果的人做出**。 |
| **5. 创意方向 (Creative Direction)** | 大想法、突破性活动、创造新品类的产品愿景。<br>**AI 是你的制作团队，你是导演**。 |

## 🗣️ 告诉客户真相
**应该让客户知道你的团队是 AI 吗？**

没有唯一正确答案，但四条准则适用：

| 指南 | 说明 |
|------|------|
| **被问及时诚实回答** | 如果客户问"我在和真人对话吗？"**说实话**。欺骗客户既不道德，也越来越违法。 |
| **考虑提前披露** | 某些业务从透明中获益：<br>*"我们的内容由 AI 生产，由人类编辑团队审查"*。<br>这传递现代、高效和诚实的信号。 |
| **永不冒充人类** | AI 客服 Agent 不应假装是"支持团队的 Jessica"。<br>它可以有名字，但**不应伪造人类身份**。 |
| **关注监管动态** | 多个司法管辖区正在制定 AI 披露要求（尤其针对客户沟通）。保持对市场需求的了解。 |

> **透明不仅是正确的，更是聪明的**。随着 AI 生成内容普及，诚实披露方法的公司将比隐藏者赢得更多信任。

## 💼 工作责任与未来
本书关于构建，但回避明显问题是不诚实的：**如果每位创始人都自动化公司，其他人的工作会怎样？**

我没有完整答案（也没有人有）。但考虑以下模式：
- **每波自动化都消灭了工作，也创造了新工作**。历史净效应是积极的，但**过渡期对受影响者总是痛苦的**。
- 流水线取代的工厂工人不会立即成为经理。转变需要数年且分布不均。

AI 将遵循相同模式：
- **某些工作会消失**。
- **新类型的工作会出现**。
- **过渡不均，对部分人确实艰难**。

### 🛡️ 作为此领域的创始人，你负有责任：
| 原则 | 行动指南 |
|------|---------|
| **创造价值而非仅提取价值** | 构建世界需要的 AI 公司：有用内容、更好产品、真实服务。<br>**而非仅靠成本削减套利**。 |
| **诚实说明你在做什么** | 不假装 AI 公司雇佣了员工。<br>不用 AI 作为偷工减料的掩护。 |
| **分享所学** | 如果你构建工具、模板或知识，公开它们。<br>**更多人理解如何用 AI 构建，益处越广泛传播**。 |
| **对预测保持谦逊** | 无人知道终点在哪。<br>负责任地构建、观察影响、调整。<br>**"AI 解决一切"或"AI 毁灭一切"的教条对任何人都无益**。 |

## 🌱 责任即长期优势
**负责任的 AI 使用是更好的商业**。"快速行动、打破常规"的群体忽略了这一点。
- **客户信任透明公司**。
- **投资者偏好有治理和控制的团队**。
- **监管将打击鲁莽运营者，而非负责任者**。

当追逐炒作的人离开时，**构建可持续、质量导向 AI 公司的创始人仍将在运行**。

责任不是构建的限制，而是**构建持久事物的基础**。

AI 是人类有史以来为放大个体能力而制造的最强大工具。但**没有手操作的工具只是金属**。
**你是那只手**。你的判断、价值观和愿景——这些让零员工公司成为真实企业，而非仅生成输出的机器。
