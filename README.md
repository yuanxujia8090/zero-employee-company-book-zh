## 📖 关于本书

本书向创始人展示如何利用 **AI Agent** 作为整个团队来构建和运营公司。
- **零员工**：无需雇佣任何人。
- **零薪资支出**：没有传统的人力成本。
- **零 HR 管理**：无需处理招聘、社保等事务。

只需一位创始人，一张由 AI Agent 组成的组织架构图，以及一个名为 **[Paperclip](https://paperclip.ing)** 的开源编排平台。

本书是开源的。你可以在此阅读、分享。
